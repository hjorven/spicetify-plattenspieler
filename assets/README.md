# Assets

Lege hier einen Screenshot oder ein GIF der laufenden App ab, z. B.:

- `screenshot.png` – Standbild (im Haupt-README verlinkt als `assets/screenshot.png`)
- `demo.gif` – optionale Kurz-Demo des rotierenden Tonarms

Empfehlung zum Aufnehmen unter Fedora/Wayland:
- Screenshot: `gnome-screenshot` oder `Umschalt+Druck` (GNOME-Standard)
- GIF: z. B. mit `peek` (`sudo dnf install peek`) einen kurzen Ausschnitt aufnehmen

Sobald eine Datei hier liegt, im Haupt-README das Bild-Tag entsprechend anpassen.
